# Screenshots

Tempat menyimpan screenshot untuk README.

## Cara pakai

1. Taruh file `.png` di folder ini, misal:
   - `ss-desktop.png` — desktop utama
   - `ss-rofi.png` — rofi launcher
   - `ss-presets.png` — preset switcher
   - `ss-btop.png` — btop monitor
   - `ss-launcher.png` — app launcher

2. Di `README.md` (English) dan `README.id.md` (Indonesia), ganti blok
   "Screenshots" dengan gambar, contoh:

   ```html
   <p align="center">
     <img src="assets/screenshots/ss-desktop.png" width="800" alt="Desktop">
   </p>
   ```

3. Kalau sudah ada video YouTube, tambah badge di bawahnya, contoh:

   ```html
   <p align="center">
     <a href="https://youtu.be/VIDEO_ID"><img src="https://img.shields.io/badge/▶️_Watch_on_YouTube-FF0000?style=for-the-badge&logo=youtube&logoColor=white" alt="YouTube"></a>
   </p>
   ```
